## How IS v2 behaves (proven)
- Scenarios contain methods; each method attaches to a zone or subzone. Status: Published / Testing / Archived.
- Testing objects show only in the Cart Tester; live `/cart/shipping_rates.json` probes confirm customers never see them.
- Within one scenario a subzone method overrides the zone method for its ZIPs (02554: $9.99 shown, $4.56 suppressed).
- A state can be in only one zone, so 6A = a "Zone 6A Islands" subzone inside Northeast (27 ZIPs MA/ME/NY/FL),
  USA (48028, 49726, 49757, 49782, 54246), DC (27960), West Coast (13 WA ZIPs). CA 90704 on HOLD.
- Editing a live method: Duplicate scenario → rename with ` REBRIEF` → Testing → edit the copy.
  Go-live = publish copy + archive original. Adding to a live scenario: new method with Status Testing.
- "Match product filters to conditions" hides the Product filters card (root cause of Free Shipping items getting paid
  rates in West Coast/DC scenarios).
- West Coast parcel: live checkout returns the cheaper of two same-named methods (591771 $72.89 over 543060 $131.20).
- Method edit form URL: `v2.intuitiveshipping.app/shippingoptions/edit/<method id>`.
